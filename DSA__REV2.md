# PART A — APTITUDE (103 POINTS)

## Quantitative Aptitude

**1. Successive Percentage Change** — `Net = a + b + ab/100`. Trap: never add percentages. Ex: 10% then 10% → 21% increase.

**2. Reverse Percentage** — If value rises by a% then falls a%, net = `-a²/100` (always a loss). Ex: 20% up, 20% down → 4% loss.

**3. Profit/Loss Basics** — `P% = (SP-CP)/CP × 100`. Trap: always divide by CP, not SP. Ex: CP 100, SP 120 → 20% profit.

**4. Two Successive Discounts** — `Net = d1 + d2 - d1d2/100`. Equivalent to successive decrease. Ex: 20% + 10% → 28% discount.

**5. MP, SP, CP Chain** — `SP = MP(1-d)(1+p)`. Trap: discount applies on MP, profit on CP.

**6. Faulty Weight Profit** — `Profit% = (Error / (True value - Error)) × 100`. Ex: 900 g instead of 1 kg → 11.11% profit.

**7. Simple Interest** — `SI = PRT/100`. Doubles in `T = 100/R` years.

**8. Compound Interest** — `A = P(1+R/100)^T`. CI = A - P.

**9. CI Half-Yearly/Quarterly** — Rate halves/divides by 4; time doubles/quadruples.

**10. SI vs CI 2-Year Difference** — `Diff = P(R/100)²`. 3-year diff = `P(R/100)²(3 + R/100)`.

**11. Ratio Manipulation** — `a:b = c:d` → ad = bc. Componendo: `(a+b)/(a-b) = (c+d)/(c-d)`.

**12. Direct vs Inverse Proportion** — Direct: more → more (`x1/y1 = x2/y2`). Inverse: more → less (`x1y1 = x2y2`).

**13. Partnership** — Profit share = Capital × Time ratio. Sleeping partner shares profit only.

**14. Average** — `Avg = Sum/Count`. Adding a value x to n items changes avg by `(x - old_avg)/(n+1)`.

**15. Weighted Average / Alligation** — `(n1/n2) = (A2 - Aw)/(Aw - A1)`. Cross-subtract rule.

**16. Mixture Replacement** — After n replacements of x from V: `Final = V(1 - x/V)^n`.

**17. Time & Work (LCM Method)** — Take total work = LCM of days; convert to units/day. Add rates.

**18. Efficiency Ratio** — Efficiency inversely proportional to time. `E1/E2 = T2/T1`.

**19. Pipes & Cisterns** — Inlet = +rate, outlet = -rate. Net rate adds algebraically.

**20. Work & Wages** — Wages proportional to work done (efficiency × time).

**21. Speed-Distance-Time** — `D = S × T`. Units: 1 km/h = 5/18 m/s.

**22. Average Speed** — Equal distances: harmonic mean `2ab/(a+b)`. Equal times: arithmetic mean.

**23. Relative Speed** — Same direction: `a - b`. Opposite: `a + b`.

**24. Train Crossing Pole/Platform** — Pole: `T = L_train/S`. Platform: `T = (L_train + L_platform)/S`.

**25. Two Trains Crossing** — Opposite: `T = (L1+L2)/(S1+S2)`. Same direction: `(L1+L2)/(S1-S2)`.

**26. Boats & Streams** — Downstream = `b + s`, Upstream = `b - s`. `b = (D+U)/2`, `s = (D-U)/2`.

**27. Races** — "A beats B by x m" → when A runs total, B runs total - x. Head start = distance advantage.

**28. Circular Track Meeting** — Same direction: `LCM(L/S1-S2)`. Opposite: `LCM(L/S1+S2)`.

**29. Ages** — Convert to one variable; use "t years ago/later" shift. Trap: ratio changes non-linearly.

**30. Divisibility Rules** — 3: digit sum. 4: last 2 digits. 8: last 3. 9: digit sum divisible by 9. 11: alternating sum.

**31. HCF / LCM** — `HCF × LCM = a × b`. HCF of fractions = `HCF(num)/LCM(den)`.

**32. LCM of Fractions** — `LCM(num)/HCF(den)`.

**33. Remainder Theorem** — `(a×b) mod m = ((a mod m)(b mod m)) mod m`. Negative remainder: add divisor.

**34. Unit Digit / Cyclicity** — Powers of 2,3,7,8 cycle in 4. 4,9 cycle in 2. 5,6,0,1 always same.

**35. Modular Arithmetic** — `(a+b) mod m`, `(a-b) mod m` distribute. Division needs modular inverse.

**36. Number of Factors** — If `N = p^a q^b r^c`, factors = `(a+1)(b+1)(c+1)`.

**37. Sum of Factors** — `[(p^(a+1)-1)/(p-1)] × [...]` for each prime.

**38. Trailing Zeros in n!** — `⌊n/5⌋ + ⌊n/25⌋ + ⌊n/125⌋ + ...`

**39. Highest Power of Prime p in n!** — `⌊n/p⌋ + ⌊n/p²⌋ + ...`

**40. Linear Equations** — Two variables: elimination or substitution. Check consistency: `a1/a2 ≠ b1/b2` → unique.

**41. Quadratic Roots** — `x = (-b ± √(b²-4ac))/2a`. Sum = `-b/a`, product = `c/a`.

**42. Inequalities Sign Scheme** — Factor, mark roots on number line, alternate signs (if no repeated roots). `<0` = negative intervals.

**43. Max/Min of Quadratic** — Vertex at `x = -b/2a`. Min if a>0, max if a<0.

**44. AP** — `aₙ = a + (n-1)d`, `Sₙ = n/2[2a + (n-1)d] = n/2(a + l)`.

**45. GP** — `aₙ = ar^(n-1)`, `Sₙ = a(rⁿ-1)/(r-1)`, infinite `S = a/(1-r)` for |r|<1.

**46. AM-GM-HM** — `AM ≥ GM ≥ HM`. AM×HM = GM². Use for min/max optimization.

**47. Permutations** — `nPr = n!/(n-r)!`. Arrangement matters.

**48. Combinations** — `nCr = n!/(r!(n-r)!)`. Selection only. `nCr = nC(n-r)`.

**49. Circular Permutation** — n people around circle: `(n-1)!`. Necklace: `(n-1)!/2`.

**50. Identical Objects** — Distribute n identical into r groups: `C(n+r-1, r-1)`.

**51. Probability Basics** — `P = favorable/total`. `P(A') = 1 - P(A)`.

**52. Independent / Mutually Exclusive** — Independent: `P(A∩B) = P(A)P(B)`. Mutually exclusive: `P(A∩B) = 0`.

**53. Conditional / Bayes** — `P(A|B) = P(A∩B)/P(B)`. Bayes: `P(A|B) = P(B|A)P(A)/P(B)`.

**54. Expected Value** — `E = Σ x·P(x)`. Linearity of expectation always holds.

**55. Mean / Median / Mode** — Median: middle of sorted. Even n: average of two middles. Mode: most frequent.

**56. Variance / SD** — `Var = Σ(x-μ)²/n`, `SD = √Var`. Outliers affect SD strongly.

**57. DI — Percentage Share** — `Share% = part/total × 100`. Watch base changes year to year.

**58. DI — Growth Rate** — `Growth% = (new - old)/old × 100`. CAGR = `(end/start)^(1/n) - 1`.

**59. Clocks — Angle** — `Angle = |30H - 5.5M|`. Take min with 360 - angle.

**60. Clocks — Coincidence/Opposite** — Coincide every 65 5/11 min. Opposite every 32 8/11 min.

**61. Calendars — Odd Days** — Ordinary year: 1 odd day. Leap year: 2. 100 years: 5. 400 years: 0.

**62. Calendars — Day Shortcut** — Count odd days from a known reference date mod 7.

## Logical Reasoning

**63. Number Series — Difference** — Check first difference; if constant → AP. If differences form pattern → second difference.

**64. Number Series — Ratio/Product** — Check ×2, ×3, ×1.5 patterns. Alternate series possible.

**65. Number Series — Squares/Cubes** — Check ±1, ±2 around n², n³, n²±n.

**66. Number Series — Mixed** — Two interleaved series (odd/even positions) is common.

**67. Alphabet Series (EJOTY)** — E=5, J=10, O=15, T=20, Y=25. Anchor points for fast position.

**68. Reverse Alphabet** — Position from end = `27 - position from start`. A↔Z, B↔Y.

**69. Coding-Decoding — Letter Shift** — Find shift (+1, +2, -1). Apply consistently.

**70. Coding-Decoding — Number/Symbol** — Map each letter to number/symbol; check for reversal or positional swap.

**71. Analogy** — Identify relation type (synonym, part-whole, cause-effect, worker-tool). Apply same relation.

**72. Classification** — Find the odd one out by category, property, or parity.

**73. Syllogism — Venn Method** — Draw all possible Venn diagrams. Conclusion must hold in **all** cases.

**74. Syllogism Traps** — "Some A are B" does NOT imply "Some B are A" is false — it's true. "All A are B" + "No B are C" → "No A are C".

**75. Statement-Conclusion** — Conclusion must follow from statement alone, not from general knowledge.

**76. Statement-Assumption** — Assumption is unstated but necessary for the statement to make sense.

**77. Cause-Effect** — Check temporal order and direct causation. Common cause possible.

**78. Blood Relations — Symbols** — Use + for male, - for female, = for couple, | for siblings. Build tree.

**79. Blood Relations — Coded** — Decode each relation symbol carefully. Track generation gaps.

**80. Direction Sense — Displacement** — Use Pythagorean theorem for net displacement. Track N/S/E/W signs.

**81. Direction Sense — Shadow** — Morning shadow points West. Evening shadow points East.

**82. Ranking** — `Total = (rank from top + rank from bottom) - 1`.

**83. Linear Seating** — Fix one person, place others relative. Note facing direction (left/right flips).

**84. Circular Seating** — Facing center: left is clockwise. Facing outside: left is anticlockwise.

**85. Puzzles — Floor/Flat** — Draw grid. Fix the most constrained clue first.

**86. Data Sufficiency** — Check each statement alone, then together. Answer: I alone, II alone, both, neither.

**87. Venn 2-Set** — `n(A∪B) = n(A) + n(B) - n(A∩B)`.

**88. Venn 3-Set** — `n(A∪B∪C) = Σn - Σn(pairs) + n(A∩B∩C)`.

**89. Logical Operators** — AND (∧): true if both. OR (∨): true if any. NOT (¬): negate. Implication `p→q` false only when p true, q false.

**90. Cube & Dice** — Cube painted: 3-face corners (8), 2-face edges, 1-face faces, 0-face center. Opposite faces sum to 7 on standard die.

## Verbal

**91. Subject-Verb Agreement** — Singular subject → singular verb. "Each/Every/Neither" take singular. Collective nouns: singular unless divided.

**92. Tenses** — Past perfect for earlier of two past actions. Present perfect for past action with present relevance.

**93. Articles** — "a" before consonant sound, "an" before vowel sound. "The" for specific/unique. No article before proper nouns, abstract nouns (general).

**94. Prepositions** — Fixed collocations: "good at", "afraid of", "interested in". Time: at (point), on (day), in (month/year).

**95. Pronouns** — Case: subject (I, he, she), object (me, him, her). Reflexive only when subject = object.

**96. Modifiers** — Modifier must be near the word it modifies. Dangling modifier = no logical subject.

**97. Parallelism** — Items in a list must have same grammatical form. "reading, writing, and swimming" not "reading, writing, to swim".

**98. Active/Passive** — Passive: object becomes subject + "be" + past participle. Only transitive verbs can be passive.

**99. Direct/Indirect** — Change pronouns, tense (backshift), time/place words. "said to" → "told".

**100. Sentence Correction Strategy** — Read for meaning first. Check subject-verb, tense, pronoun, modifier, parallelism in that order.

**101. Vocabulary** — Use roots/prefixes/suffixes. In context, replace with each option and check meaning.

**102. Para-jumbles** — Find opening sentence (independent, introduces topic). Find mandatory pairs (pronoun references, connectors).

**103. Reading Comprehension** — Skim for structure, then read questions, then locate answers. Avoid extreme options.

# PART B — C/C++ HIGH-YIELD REVISION

## 55 Core Points

1. **Pointer** — Stores address. `int *p = &x;` `*p` dereferences. Size of pointer = 8 bytes (64-bit) regardless of type.
2. **Pointer Arithmetic** — `p + 1` advances by `sizeof(*p)` bytes, not 1 byte.
3. **Array Decay** — Array name decays to pointer to first element in most expressions. `arr[i] = *(arr + i)`.
4. **Pointer to Array** — `int (*p)[5]` is pointer to array of 5 ints. `int *p[5]` is array of 5 pointers.
5. **Reference** — Alias; must be initialized; cannot be null or rebound. `int &r = x;`
6. **Pass by Value vs Reference** — Value copies; reference aliases. Arrays always decay to pointer (pass by address).
7. **const Pointer** — `const int *p` → data const. `int * const p` → pointer const. `const int * const p` → both.
8. **const Member Function** — `void f() const;` cannot modify members. Callable on const objects.
9. **static Local** — Initialized once, retains value between calls, lifetime = program.
10. **static Global** — Internal linkage (file scope only).
11. **static Member** — Shared by all objects; no `this`; define outside class.
12. **Stack vs Heap** — Stack: automatic, fast, limited size. Heap: `new`/`malloc`, manual free, large.
13. **new/delete** — `new` calls constructor; `delete` calls destructor. `new[]`/`delete[]` for arrays. Mismatch = UB.
14. **Memory Leak** — `new` without `delete`. Use smart pointers in C++17.
15. **unique_ptr** — Exclusive ownership; move-only. `make_unique<T>(...)`.
16. **shared_ptr** — Reference counted; `make_shared<T>(...)`. Cycles leak — use `weak_ptr`.
17. **Recursion** — Base case + recursive case. Each call adds stack frame. Depth O(N) can overflow.
18. **Tail Recursion** — Recursive call is last operation. Some compilers optimize to loop.
19. **Function Overloading** — Same name, different parameter list. Return type alone cannot distinguish.
20. **Default Arguments** — Must be trailing. Cannot be redefined in definition if given in declaration.
21. **Class vs Struct** — Class: private by default. Struct: public by default.
22. **Constructor** — Same name as class, no return type. Default, parameterized, copy.
23. **Copy Constructor** — `T(const T&)`. Called on pass-by-value, return-by-value, initialization.
24. **Shallow vs Deep Copy** — Shallow copies pointer (double free risk). Deep allocates new memory.
25. **Destructor** — `~T()`, no arguments, called on scope exit/delete. Virtual if polymorphic.
26. **Inheritance** — `public`, `protected`, `private`. Public inheritance = "is-a".
27. **Virtual Function** — Enables runtime polymorphism via vtable. Override in derived.
28. **Pure Virtual** — `virtual void f() = 0;` makes class abstract.
29. **Virtual Destructor** — Required when deleting derived via base pointer.
30. **Function Overriding** — Same signature in derived; needs `virtual` in base.
31. **Function Hiding** — Derived function hides base if no `virtual` or different signature.
32. **Operator Overloading** — `T operator+(const T&)`. Cannot overload `::`, `.`, `?:`, `sizeof`.
33. **STL vector** — Dynamic array. `push_back` amortized O(1). `reserve` avoids reallocation.
34. **vector<bool>** — Specialized, not a real container of bool; avoid for performance.
35. **string** — `substr`, `find`, `append`, `compare`. `s.size()` returns `size_t` (unsigned).
36. **stack** — LIFO. `push`, `pop`, `top`, `empty`. O(1) all.
37. **queue** — FIFO. `push`, `pop`, `front`, `back`. O(1) all.
38. **deque** — Double-ended. O(1) push/pop both ends. Random access O(1).
39. **priority_queue** — Max-heap by default. `priority_queue<int, vector<int>, greater<int>>` for min-heap.
40. **set / map** — Red-black tree. Ordered. O(log N) insert/find/erase.
41. **unordered_set / unordered_map** — Hash table. O(1) average, O(N) worst.
42. **pair** — `make_pair(a,b)` or `{a,b}`. Access `.first`, `.second`.
43. **Iterator** — `begin()`, `end()`. `end()` points past last. Range-based for uses these.
44. **Iterator Invalidation** — vector: reallocation invalidates all. map/set: only erased iterator.
45. **sort** — `sort(v.begin(), v.end())`. O(N log N). Not stable. `stable_sort` is stable.
46. **Custom Comparator** — `sort(v.begin(), v.end(), [](int a, int b){ return a > b; });` Strict weak ordering required.
47. **Lambda** — `[capture](params){ body }`. Capture by value `[=]`, by reference `[&]`.
48. **lower_bound** — First element `>= x`. O(log N) on sorted range.
49. **upper_bound** — First element `> x`. O(log N) on sorted range.
50. **binary_search** — Returns bool. Requires sorted range.
51. **Integer Overflow** — `int` ~2.1×10⁹. Use `long long` for sums/products. `INT_MAX + 1` = UB.
52. **Unsigned Underflow** — `0u - 1` = UINT_MAX. Mixing signed/unsigned promotes to unsigned.
53. **Recursion Stack** — Depth > ~10⁵ risks stack overflow. Convert to iterative or increase stack.
54. **Fast I/O** — `ios::sync_with_stdio(false); cin.tie(nullptr);` for competitive input.
55. **auto & Structured Bindings** — `auto [a,b] = mp.begin()->second;` (C++17).

## 25 Output/Debugging Concepts

1. `int i = 5; cout << i++ + ++i;` → UB (no sequence point). Avoid.
2. `int i = 5; cout << i++ << " " << i;` → 5 6 (evaluation order unspecified in C++14; left-to-right in C++17 for `<<`? Actually still UB in C++17 for same variable). Avoid.
3. `int a[5] = {1,2,3}; cout << a[3];` → 0 (rest zero-initialized).
4. `char *s = "abc"; s[0] = 'x';` → UB (string literal in read-only memory).
5. `int *p = NULL; cout << *p;` → segmentation fault.
6. `int x = 10; int &r = x; r++; cout << x;` → 11.
7. `void f(int &x){ x++; } int a = 5; f(a); cout << a;` → 6.
8. `void f(int x){ x++; } int a = 5; f(a); cout << a;` → 5 (pass by value).
9. `static int c = 0; c++;` inside function → retains value across calls.
10. `int i = 0; while(i++ < 3); cout << i;` → 4.
11. `for(int i=0; i<5; i++); cout << i;` → compile error (scope).
12. `cout << sizeof('a');` → 1 (char in C++).
13. `cout << sizeof("a");` → 2 (includes null terminator).
14. `int a = 5; cout << a/2;` → 2 (integer division).
15. `cout << 5/2.0;` → 2.5 (double division).
16. `cout << (int)3.9;` → 3 (truncation, not rounding).
17. `Base *b = new Derived(); b->f();` → calls Derived::f() only if `f` is virtual.
18. `Base b = Derived(); b.f();` → object slicing; calls Base::f().
19. `vector<int> v; v.push_back(1); cout << v.capacity();` → usually 1 or more, implementation-defined growth.
20. `map<int,int> m; m[5]; cout << m.size();` → 1 (operator[] inserts default).
21. `set<int> s; s.insert(3); s.insert(3); cout << s.size();` → 1.
22. `string s = "abc"; cout << s.size() - 5;` → huge unsigned number (underflow).
23. `int a = 1; cout << (a << 31);` → UB for signed overflow.
24. `cout << 1/0;` → compile warning / runtime crash (integer division by zero).
25. `struct A { virtual void f(){ cout<<"A"; } }; struct B:A { void f(){ cout<<"B"; } }; A *p = new B(); p->f();` → B.

## 1. Maximum Subarray Sum

### Problem Statement
Find the contiguous subarray with the largest sum.

### Key Observation
At each index, either extend the previous subarray or start fresh.

### Pattern
Kadane's algorithm (1D DP / greedy).

### Brute Force
Check all O(N²) subarrays, O(N³) with sum recomputation.

### Why It Fails
Too slow for N up to 10⁵.

### Optimal Strategy
Maintain `cur = max(a[i], cur + a[i])` and track global max.

### Step-by-Step
1. `cur = a[0]`, `best = a[0]`.
2. For i = 1..n-1: `cur = max(a[i], cur + a[i])`, `best = max(best, cur)`.
3. Return best.

### C++17 Solution
```cpp
int maxSubArray(vector<int>& a) {
    int cur = a[0], best = a[0];
    for (int i = 1; i < (int)a.size(); i++) {
        cur = max(a[i], cur + a[i]);
        best = max(best, cur);
    }
    return best;
}
```

### Complexity
Time: O(N). Space: O(1).

### Edge Cases
- All negative → returns largest single element.
- Single element.
- Zeros mixed with negatives.

### Interview Explanation
Kadane's works because the best subarray ending at i is either a[i] alone or the best ending at i-1 plus a[i]. We track the running best and the global best in one pass.

## 2. Product of Array Except Self

### Problem Statement
Return array where `out[i]` = product of all elements except `a[i]`, without division.

### Key Observation
`out[i] = prefix[i-1] × suffix[i+1]`.

### Pattern
Prefix/suffix product.

### Brute Force
Nested loops O(N²).

### Why It Fails
Too slow; division fails with zeros.

### Optimal Strategy
Two passes: left-to-right prefix into output, right-to-left suffix multiplied in.

### Step-by-Step
1. `out[i] = product of a[0..i-1]`.
2. Traverse right to left, maintain `suf`, multiply into `out[i]`.

### C++17 Solution
```cpp
vector<int> productExceptSelf(vector<int>& a) {
    int n = a.size();
    vector<int> out(n, 1);
    int pre = 1;
    for (int i = 0; i < n; i++) { out[i] = pre; pre *= a[i]; }
    int suf = 1;
    for (int i = n - 1; i >= 0; i--) { out[i] *= suf; suf *= a[i]; }
    return out;
}
```

### Complexity
Time: O(N). Space: O(1) extra (output not counted).

### Edge Cases
- Contains zero(s).
- Single element.
- Negative numbers.

### Interview Explanation
Division is disallowed and breaks on zeros. Prefix/suffix products avoid both issues and run in linear time with constant extra space.

## 3. Merge Intervals

### Problem Statement
Merge all overlapping intervals.

### Key Observation
After sorting by start, overlapping intervals are adjacent.

### Pattern
Sorting + intervals.

### Brute Force
Repeatedly merge pairs until stable — O(N²).

### Why It Fails
Slow and messy.

### Optimal Strategy
Sort by start; push or merge into result.

### Step-by-Step
1. Sort by start.
2. For each interval: if it overlaps last in result, extend end; else push.

### C++17 Solution
```cpp
vector<vector<int>> merge(vector<vector<int>>& iv) {
    sort(iv.begin(), iv.end());
    vector<vector<int>> res;
    for (auto& x : iv) {
        if (!res.empty() && x[0] <= res.back()[1])
            res.back()[1] = max(res.back()[1], x[1]);
        else res.push_back(x);
    }
    return res;
}
```

### Complexity
Time: O(N log N). Space: O(N).

### Edge Cases
- Single interval.
- Touching intervals `[1,2],[2,3]` → merge.
- Fully contained interval.

### Interview Explanation
Sorting by start guarantees that any overlap is with the most recent merged interval, so one linear scan suffices.

### Interview Explanation

## 5. Subarray Sum Equals K

### Problem Statement
Count subarrays whose sum equals K.

### Key Observation
`sum(i..j) = pre[j] - pre[i-1]`. Need `pre[j] - K` seen before.

### Pattern
Prefix sum + hashing.

### Brute Force
O(N²) sum check.

### Why It Fails
Too slow.

### Optimal Strategy
Hash map of prefix-sum frequencies; initialize `mp[0] = 1`.

### C++17 Solution
```cpp
int subarraySum(vector<int>& a, int k) {
    unordered_map<int,int> mp; mp[0] = 1;
    int sum = 0, cnt = 0;
    for (int x : a) {
        sum += x;
        cnt += mp[sum - k];
        mp[sum]++;
    }
    return cnt;
}
```

### Complexity
Time: O(N). Space: O(N).

### Edge Cases
- Negative numbers (prefix sums not monotonic).
- K = 0.
- All zeros.

### Interview Explanation
Any subarray ending at j with sum K corresponds to a prefix sum `pre[j]-K` seen earlier. Counting frequencies of prefix sums gives the answer in one pass.

## 6. Longest Consecutive Sequence

### Problem Statement
Find length of the longest run of consecutive integers in an unsorted array.

### Key Observation
Only start counting from numbers whose predecessor is absent.

### Pattern
Hashing.

### Brute Force
Sort then scan — O(N log N).

### Why It Fails
Sorting is not optimal; duplicates and negatives handled but O(N log N).

### Optimal Strategy
Insert all into a set; for each `x` with `x-1` absent, count upward.

### C++17 Solution
```cpp
int longestConsecutive(vector<int>& a) {
    unordered_set<int> s(a.begin(), a.end());
    int best = 0;
    for (int x : s) {
        if (s.count(x - 1)) continue;
        int y = x;
        while (s.count(y)) y++;
        best = max(best, y - x);
    }
    return best;
}
```

### Complexity
Time: O(N) average. Space: O(N).

### Edge Cases
- Empty array.
- Duplicates.
- Negative numbers.

### Interview Explanation
Each sequence is traversed only from its start, so total work is O(N). The set gives O(1) lookups.

## 7. Longest Substring Without Repeating Characters

### Problem Statement
Length of the longest substring with all distinct characters.

### Key Observation
Maintain a window with no duplicates; shrink from left when a repeat appears.

### Pattern
Sliding window + hashing.

### Brute Force
Check all substrings O(N²).

### Why It Fails
Slow.

### Optimal Strategy
`last[c]` stores last index of c; move left past it.

### C++17 Solution
```cpp
int lengthOfLongestSubstring(string s) {
    vector<int> last(128, -1);
    int left = 0, best = 0;
    for (int r = 0; r < (int)s.size(); r++) {
        if (last[s[r]] >= left) left = last[s[r]] + 1;
        last[s[r]] = r;
        best = max(best, r - left + 1);
    }
    return best;
}
```

### Complexity
Time: O(N). Space: O(1) (fixed alphabet).

### Edge Cases
- Empty string.
- All same characters.
- All distinct.

### Interview Explanation
The window always contains distinct characters. When a repeat is found, we jump the left pointer just past the previous occurrence, avoiding redundant shrinking.

## 8. 3Sum

### Problem Statement
Find all unique triplets summing to zero.

### Key Observation
Fix one element, then two-pointer on the rest.

### Pattern
Sort + two pointers.

### Brute Force
O(N³) triple loop.

### Why It Fails
Too slow; duplicates hard to handle.

### Optimal Strategy
Sort; for each i, two-pointer from i+1 to end; skip duplicates.

### C++17 Solution
```cpp
vector<vector<int>> threeSum(vector<int>& a) {
    sort(a.begin(), a.end());
    vector<vector<int>> res;
    int n = a.size();
    for (int i = 0; i < n - 2; i++) {
        if (i && a[i] == a[i-1]) continue;
        int l = i + 1, r = n - 1;
        while (l < r) {
            int s = a[i] + a[l] + a[r];
            if (s == 0) {
                res.push_back({a[i], a[l], a[r]});
                while (l < r && a[l] == a[l+1]) l++;
                while (l < r && a[r] == a[r-1]) r--;
                l++; r--;
            } else if (s < 0) l++;
            else r--;
        }
    }
    return res;
}
```

### Complexity
Time: O(N²). Space: O(1) extra.

### Edge Cases
- All zeros.
- Duplicates.
- Fewer than 3 elements.

### Interview Explanation
Sorting enables two-pointer and duplicate skipping. Each i contributes O(N) work, giving O(N²) overall.

## 10. Trapping Rain Water

### Problem Statement
Compute total trapped water between bars.

### Key Observation
Water at i = `min(maxLeft[i], maxRight[i]) - h[i]`.

### Pattern
Two pointers / prefix max.

### Brute Force
For each i, scan left and right O(N²).

### Why It Fails
Slow.

### Optimal Strategy
Two pointers with running maxLeft and maxRight.

### C++17 Solution
```cpp
int trap(vector<int>& h) {
    int l = 0, r = h.size() - 1, lm = 0, rm = 0, ans = 0;
    while (l < r) {
        if (h[l] < h[r]) {
            lm = max(lm, h[l]);
            ans += lm - h[l];
            l++;
        } else {
            rm = max(rm, h[r]);
            ans += rm - h[r];
            r--;
        }
    }
    return ans;
}
```

### Complexity
Time: O(N). Space: O(1).

### Edge Cases
- Empty array.
- Monotonic heights (no water).
- Single bar.

### Interview Explanation
At each step the smaller side determines the water level because the other side is at least as tall. This gives O(N) without extra arrays.

## 11. Sliding Window Maximum

### Problem Statement
Return max of every window of size K.

### Key Observation
Maintain a decreasing deque of indices.

### Pattern
Monotonic deque.

### Brute Force
O(NK).

### Why It Fails
Slow for large N, K.

### Optimal Strategy
Deque front is the max; pop back while smaller; pop front when out of window.

### C++17 Solution
```cpp
vector<int> maxSlidingWindow(vector<int>& a, int k) {
    deque<int> dq;
    vector<int> res;
    for (int i = 0; i < (int)a.size(); i++) {
        while (!dq.empty() && dq.front() <= i - k) dq.pop_front();
        while (!dq.empty() && a[dq.back()] <= a[i]) dq.pop_back();
        dq.push_back(i);
        if (i >= k - 1) res.push_back(a[dq.front()]);
    }
    return res;
}
```

### Complexity
Time: O(N). Space: O(K).

### Edge Cases
- K = 1.
- K = N.
- All equal.

### Interview Explanation
Each index enters and leaves the deque once, so total work is O(N). The deque keeps candidates in decreasing order.

### Pattern
Modified binary search.

### C++17 Solution

int search(vector<int>& a, int t) {

## 16. Detect Cycle + Find Start

### Key Observation

Fast/slow pointers.

### C++17 Solution

        slow = slow->next;

        if (slow == fast) {

- Single node with self-loop.

### Interview Explanation
Floyd's detects a cycle in O(N) and O(1) space. The meeting point and head are equidistant from the cycle start.

## 31. Course Schedule (Cycle Detection)

### Problem Statement
Determine if all courses can be finished given prerequisites.

### Key Observation
Cycle in the prerequisite graph → impossible.

### Pattern
Topological sort / DFS.

### C++17 Solution (Kahn's)
```cpp
bool canFinish(int n, vector<vector<int>>& pre) {
    vector<vector<int>> adj(n);
    vector<int> indeg(n, 0);
    for (auto& p : pre) { adj[p[1]].push_back(p[0]); indeg[p[0]]++; }
    queue<int> q;
    for (int i = 0; i < n; i++) if (!indeg[i]) q.push(i);
    int done = 0;
    while (!q.empty()) {
        int u = q.front(); q.pop(); done++;
        for (int v : adj[u]) if (--indeg[v] == 0) q.push(v);
    }
    return done == n;
}
```

### Complexity
Time: O(V+E). Space: O(V+E).

### Edge Cases
- No prerequisites.
- Self-loop.
- Disconnected graph.

### Interview Explanation
Kahn's algorithm removes nodes with indegree 0. If all nodes are removed, no cycle exists.

## 32. Network Delay Time (Dijkstra)

### Problem Statement
Find time for all nodes to receive a signal from source K.

### Pattern
Dijkstra.

### C++17 Solution
```cpp
int networkDelayTime(vector<vector<int>>& times, int n, int k) {
    vector<vector<pair<int,int>>> adj(n + 1);
    for (auto& t : times) adj[t[0]].push_back({t[1], t[2]});
    vector<int> dist(n + 1, INT_MAX);
    priority_queue<pair<int,int>, vector<pair<int,int>>, greater<>> pq;
    dist[k] = 0; pq.push({0, k});
    while (!pq.empty()) {
        auto [d, u] = pq.top(); pq.pop();
        if (d > dist[u]) continue;
        for (auto [v, w] : adj[u]) {
            if (dist[u] + w < dist[v]) {
                dist[v] = dist[u] + w;
                pq.push({dist[v], v});
            }
        }
    }
    int ans = 0;
    for (int i = 1; i <= n; i++) {
        if (dist[i] == INT_MAX) return -1;
        ans = max(ans, dist[i]);
    }
    return ans;
}
```

### Complexity
Time: O((V+E) log V). Space: O(V+E).

### Edge Cases
- Unreachable node.
- Single node.
- Multiple edges.

### Interview Explanation
Dijkstra with a min-heap gives shortest distances. The answer is the maximum finite distance.

## 33. Redundant Connection (DSU)

### Problem Statement
Find the edge that creates a cycle in a tree.

### Pattern
Union-Find.

### C++17 Solution
```cpp
struct DSU {
    vector<int> p, r;
    DSU(int n) : p(n + 1), r(n + 1, 0) { iota(p.begin(), p.end(), 0); }
    int find(int x) { return p[x] == x ? x : p[x] = find(p[x]); }
    bool unite(int a, int b) {
        a = find(a); b = find(b);
        if (a == b) return false;
        if (r[a] < r[b]) swap(a, b);
        p[b] = a;
        if (r[a] == r[b]) r[a]++;
        return true;
    }
};
vector<int> findRedundantConnection(vector<vector<int>>& edges) {
    DSU d(edges.size());
    for (auto& e : edges)
        if (!d.unite(e[0], e[1])) return e;
    return {};
}
```

### Complexity
Time: O(N α(N)) ≈ O(N). Space: O(N).

### Edge Cases
- Single edge.
- Cycle involving first edge.
- Multiple cycles.

### Interview Explanation
Adding edges to DSU, the first edge whose endpoints are already connected creates the cycle.

## 34. Coin Change

### Problem Statement
Minimum coins to make amount.

### Key Observation
`dp[x] = min(dp[x - coin] + 1)` over all coins.

### Pattern
Unbounded knapsack / 1D DP.

### C++17 Solution
```cpp
int coinChange(vector<int>& coins, int amount) {
    vector<int> dp(amount + 1, amount + 1);
    dp[0] = 0;
    for (int x = 1; x <= amount; x++)
        for (int c : coins)
            if (c <= x) dp[x] = min(dp[x], dp[x - c] + 1);
    return dp[amount] > amount ? -1 : dp[amount];
}
```

### Complexity
Time: O(N × amount). Space: O(amount).

### Edge Cases
- Amount 0.
- Impossible amount.
- Coin = 1 always possible.

### Interview Explanation
Bottom-up DP fills the minimum coins for every amount up to target.

## 36. Edit Distance

### Problem Statement
Minimum insert/delete/replace to convert word1 to word2.

### Key Observation
`dp[i][j]` = edit distance of prefixes.

### Pattern
2D DP.

### C++17 Solution
```cpp
int minDistance(string a, string b) {
    int n = a.size(), m = b.size();
    vector<vector<int>> dp(n + 1, vector<int>(m + 1));
    for (int i = 0; i <= n; i++) dp[i][0] = i;
    for (int j = 0; j <= m; j++) dp[0][j] = j;
    for (int i = 1; i <= n; i++)
        for (int j = 1; j <= m; j++)
            if (a[i-1] == b[j-1]) dp[i][j] = dp[i-1][j-1];
            else dp[i][j] = 1 + min({dp[i-1][j], dp[i][j-1], dp[i-1][j-1]});
    return dp[n][m];
}
```

### Complexity
Time: O(N×M). Space: O(N×M).

### Edge Cases
- Empty strings.
- One empty.
- Identical strings.

### Interview Explanation
Classic 2D DP: match characters or pay 1 for insert/delete/replace.

**Core Idea:** `dp[i][j] = max over k of dp[i][k] + dp[k][j] + a[i]*a[k]*a[j]`.
**Expected Complexity:** O(N³) time.
**Key Trap:** Pad with 1s at both ends.

### Problem 100 — Single Number / Rotate Image
**Pattern:** XOR / matrix transpose.
**Core Idea:** XOR cancels duplicates. Rotate: transpose then reverse rows.
**Expected Complexity:** O(N) / O(N²) time.
**Key Trap:** In-place rotation requires care.

## How to Break an Incorrect Solution (10 Examples)

1. **Two Sum with duplicates** — `[3,3], target 6`. A solution using a set (not map) fails.
2. **Kadane with all negatives** — `[-3,-1,-2]`. A solution initializing `best = 0` returns 0 instead of -1.

# PART I —  INTERVIEW SOLVING STRATEGY

## How to Solve a Coding Problem

1. **Read constraints** — N, value ranges, time limit.
2. **Identify input structure** — Array, string, tree, graph, matrix.
3. **State brute force** — Even if obvious, say it.
4. **Find bottleneck** — What makes it slow?
5. **Identify pattern** — Hashing, two pointers, DP, etc.
6. **Derive optimized approach** — Explain the improvement.
7. **State complexity** — Time and space before coding.
8. **Code** — Clean, meaningful names, no magic numbers.
9. **Dry run** — Trace a small example.
10. **Test edge cases** — Empty, single, duplicates, overflow.
11. **Explain optimality** — Why this is the best approach.

## If Stuck for 5 Minutes
- Re-read the problem statement carefully.
- Check constraints — they hint at the expected complexity.
- Try small examples by hand.
- Consider: sorting? hashing? two pointers? binary search?
- Start with brute force and optimize.

## If Brute Force Works But Is Too Slow
- Identify the repeated work.
- Can you cache results? (DP / memoization)
- Can you sort and use two pointers?
- Can you use a hash map for O(1) lookups?
- Can you binary search the answer?
- Can you use a heap for top-K?

## If Interviewer Asks for Better Complexity
- State the current complexity.
- Identify the bottleneck operation.
- Propose the trade-off (usually space for time).
- Explain the new approach and its complexity.

## If Code Fails
- Check boundary conditions: `lo <= hi` vs `lo < hi`.
- Check off-by-one: array indices, loop bounds.
- Check integer overflow: use `long long`.
- Check empty/null input.
- Check duplicate handling.
- Check variable initialization.
- Trace with the smallest failing case.

# PART J — 10 QUESTION-VALIDATION EXERCISES

**1. Ambiguity** — "Find the longest substring." → Longest by length or lexicographic? Answer: Ambiguous; specify "longest by length."

**2. Missing constraint** — "Find two numbers that sum to target." → Are there duplicates? Is there always a solution? Answer: Missing; specify uniqueness and guarantee.

**3. Incorrect expected output** — "Input: [1,2,3], target 3. Expected: [0,1]." → 1+2=3, but also 0+2=3 if 3 is present? Answer: Check if the array contains the target value itself.

**4. Missing edge case** — "Sort an array." → No mention of empty array or single element. Answer: Add empty and single-element tests.

**5. Inefficient solution** — "Use nested loops to find duplicates." → O(N²). Answer: Use a hash set for O(N).

**6. Integer overflow** — "Sum of array elements." → If elements up to 10^9 and N up to 10^5, sum exceeds int. Answer: Use `long long`.

**7. Duplicate handling** — "Find all triplets summing to zero." → Duplicates in input produce duplicate triplets. Answer: Skip duplicates in the sorted array.

**8. Off-by-one** — "Return the middle element." → For even length, which middle? Answer: Specify first or second middle.

**9. Wrong complexity** — "Binary search on unsorted array." → O(log N) claim is wrong. Answer: Must sort first (O(N log N)) or use linear search.

**10. Insufficient hidden tests** — "Reverse a string." → Only tested with "hello". Answer: Add empty string, single char, palindrome, spaces, unicode.
